# Intro sound resources

## Laughing kookaburra

- Original master: `laughing-kookaburra-kuco.ogg` (retained unchanged).
- Website copy: `assets/audio/laughing-kookaburra.ogg`.
- Recorder: Kuco.
- Recording: laughing kookaburra in south-west Australia, December 2007.
- Source: https://commons.wikimedia.org/wiki/File:LaughingKookaburra.ogg
- Original file: https://upload.wikimedia.org/wikipedia/commons/c/ca/LaughingKookaburra.ogg
- Rights: public-domain dedication by the recorder on the source page, verified 28 October 2026. The recorder permits use for any purpose without conditions where a public-domain dedication is not possible.
- Local website use: a short excerpt selected from the recording, with volume adjustment and fades applied during playback; no loop. The source file is not edited.

The iron sizzle and telex ticks are synthesized in `hero-audio.js`. The Australian male voice trial was rejected and removed. Audio remains a local preview until Craig authorises publication.
